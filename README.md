# Sibered — static dashboard (no build step)

Plain HTML/CSS/JS, flat files — works directly on GitHub Pages, no npm/build required.

## Files
index.html (Home), websites.html, add-website.html, verify.html, scan.html,
report.html, reports.html, billing.html, settings.html
style.css, script.js, logo.png, donato-regular.ttf

## Host on GitHub Pages
1. Push all these files to the ROOT of your repo (not inside a subfolder)
2. Repo Settings → Pages → Source: "main" branch, "/ (root)"
3. Your site goes live at https://YOUR-USERNAME.github.io/YOUR-REPO/

All data on these pages is hardcoded placeholder data — no backend is connected yet.
